# Payload CMS Navigation Structure

## 📊 Collection Groups

Collections in Payload are organized into logical groups for easy navigation.

### Content
- Tours
- Stories
- Testimonials
- FAQs
- Media Coverage
- Media (image library)

### Landing Pages
- Dietary Landing Pages
- Specialty Landing Pages
- Travel Type Landing Pages
- Location Landing Pages

### Pages
- About Page
- Contact Page
- Thank You Pages

### Settings & Config
- Site Settings
- Translations
- Users
- Redirects

## 🎯 Admin URL Structure

Access collections directly:
- `/admin/collections/tours` - Tour listings
- `/admin/collections/stories` - Blog posts
- `/admin/collections/media` - Image library
- `/admin/collections/site-settings` - Global settings
