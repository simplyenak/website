## Setup Instructions

1. Go to https://app.vbout.com/Campaigns
2. Click "Create Campaign"
3. Choose "Email Marketing" → "Standard Campaign"
4. Select List: "WTM Subscribers"
5. Paste the HTML template
6. Set subject line
7. Preview and send test email
8. Schedule or send immediately
