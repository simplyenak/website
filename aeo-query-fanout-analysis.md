# Simply Enak — Query Fan-Out (AEO) Analysis

**Date:** 2026-09-03
**Method:** Synthetic query fan-out per AEO practice. AI search engines (ChatGPT, Claude, Perplexity, Google AI Overviews, AI Mode) decompose one user prompt into 8-20 parallel sub-queries, retrieve answers for each, then synthesize a single cited answer. A brand is cited in the final answer **only if it appears across enough of the sub-query results** — not by ranking for one keyword. Winning AEO means covering the whole fan-out cluster.

This analysis maps fan-outs for Simply Enak's four core topics, assigns each a customer persona, classifies on-site vs off-site, checks live coverage, and prioritizes gap-closing actions.

### Persona MAPPING — the key lever (from the 723% case study)
Enak's different buying personas trigger **different fan-outs**:
- **Architect-type / corporate planner →** specs: capacity, group size, food-safety, logistics, insurance-none, ability to host 10-50 people, team size.
- **School / headteacher →** kids safety, gentle pace, allergy handling, educative value, wet weather plan.
- **Family →** kids, tolerated spice levels, patience with fussy eaters, schedule (morning, before bedtime).
- **HALAL-conscious →** certified/trusted stalls, no-pork, how vetted.
- **Vegetarian →** hidden animal products (oyster sauce, shrimp paste), stall adaptation.

> **Action:** Run one fan-out map *per persona*, not one per topic. The case study's 723% gain came from mapping every customer persona.

8. **Location fan-outs** (Chow Kit, Pudu, Chinatown, Petaling Street) each a queryable sub-topic.

## Tools for generating and tracking fan-outs

| Tool | What it does | Cost/access |
|------|--------------|-------------|
| **RankOS** | Best-in-class *query fan-out discovery* (used in the 723% case study); categorizes fan-outs (listicle, external source, etc.) | Paid + Skool-group invite only |
| **Semrush One** | Visibility/reporting across AI surfaces | Paid subscription |
| **OpenSEO** | Open-source (MIT, ~US$10/mo or self-host + DataForSEO key). Tracks **AI brand visibility** (brand-in-AI-answer, citations, prompt explorer) — but does **NOT** do fan-out *discovery* like RankOS. | Cheap/good for measuring, not for discovery |
| **AgentSearch / internal search API** | Synthetic query generation via search APIs (can produce reasoned fan-outs) | Internal |
| **Manual LLM prompt (free)** | Ask ChatGPT/Claude: *"You are the retrieval planner for a Malaysian food tour search. For the query 'food tour Kuala Lumpur', list the 15 sub-queries you would run in parallel — one per constraint, comparison, persona, location and trust signal."* Then repeat with a persona framing ("I am a headteacher planning a school trip," "I am halal-conscious," "I am a solo traveler"). | Free — start here |

### Recommended ongoing workflow (manual, no paywall)
1. **Weekly:** pick 1 core topic + 3 personas. Ask the LLM planner prompt to enumerate the fan-out.
2. **Tag each** sub-query ON-site / OFF-site.
3. **Audit live coverage** (simplyenak.com + competitor SERPs via web search).
4. **Write the missing passage** as a question-format H2 + direct paragraph answer.
5. **Off-site:** for each trust-signal fan-out (reviews, listicles, awards), add one amplification action — see `amplification-workflow.md`.
6. **Track visibility** monthly with OpenSEO (or Semrush One) to see brand-in-AI answers move.
7. Log every asset in the amplification tracker CSV.

## Note on brand voice
Google's own AEO guide warns against "seeking inauthentic mentions" and "AEO hacks" (chunking, fake llms.txt) — so don't game. Write genuinely useful, people-first content; the fan-out won't be won by thin keyword stuffing. Keep the Passionate-Friend voice: no "authentic", no superlatives, no em-dashes, always "Simply Enak".
