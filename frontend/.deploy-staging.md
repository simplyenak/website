# Deployment Instructions

## Current Setup
- **Production**: `simplyenak.com` (main branch)
- **Staging**: [Your staging domain] (test branches)
- **CDN**: [Your CDN domain] (has specific routing rules)

## Important Note:
DO NOT deploy test/feature branches to the CDN application due to specific routing rules that override individual page routing.

## Recommended Deployment:
1. Use the **Staging application** for test branches like `kl-page-cleanup`, `test-simple-route`, etc.
2. Keep the **CDN application** for production CDN purposes only
3. The **Production application** should only deploy from `main` branch

## Branch Configuration:
- `main` → Production application
- `test-*`, `staging-*`, `kl-*` → Staging application
- CDN application → Only production deployments
