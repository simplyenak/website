## 🚀 STEP-BY-STEP BING SETUP

### Step 1: Create Microsoft Account (5 minutes)
```
Already have? Skip to Step 2
Need one? Visit: https://account.microsoft.com/account
Use: info@simplyenak.com or your business email
```

### Step 2: Access Bing Webmaster Tools (2 minutes)
```
URL: https://www.bing.com/webmasters/
Click: "Sign in" with Microsoft account
```

### Step 3: Add Your Website (3 minutes)
```
1. Click "Add a site"
2. Enter: https://simplyenak.com
3. Click "Add"
```

### Step 4: Verify Domain Ownership (10 minutes)

#### Method 1: Meta Tag (Recommended)
```
1. Choose "Meta tag" verification
2. Copy the meta tag provided by Bing
3. Add to your homepage <head> section
4. Wait 10-15 minutes
5. Click "Verify"
```

#### Method 2: DNS TXT Record (Alternative)
```
1. Choose "DNS" verification
2. Copy the TXT record provided
3. Add to your DNS settings
4. Wait up to 24 hours for DNS propagation
5. Click "Verify"
```

### Step 5: Submit Sitemap (5 minutes)
```
1. Go to "Sitemaps" in Bing Webmaster Tools
2. Click "Submit a sitemap"
3. Enter: https://simplyenak.com/sitemap-index.xml
4. Click "Submit"
```

### Step 6: Configure Settings (15 minutes)

#### Geographic Targeting:
```
1. Go to "Configure My Site" → "Geographic targeting"
2. Select: "Malaysia" (primary)
3. Add: "International" (secondary)
4. Save settings
```

#### Crawl Rate:
```
1. Go to "Configure My Site" → "Crawl control"
2. Set: "Normal" crawl rate
3. Set: "Daily" crawl frequency
4. Save settings
```

#### URL Parameters:
```
1. Go to "Configure My Site" → "URL Parameters"
2. Add: "utm_*" (Do not crawl)
3. Add: "fbclid" (Do not crawl)
4. Add: "gclid" (Do not crawl)
5. Save settings
```
