## How to Import to Directus

1. Go to Directus → Tours
2. Select each tour by slug
3. Paste the JSON into the `itinerary` field
4. Save and publish

**Note:** Each itinerary has 6 stops with:
- `time`: Tour time
- `title`: Stop name
- `description`: What happens there
- `tastings`: Array of food items
- `cultural_context`: The story behind the stop
