## ✅ Extraction Checklist

### Phase 1: Initial Pass (2-3 hours)

- [ ] Read full transcript once (no notes)
- [ ] Read full transcript second time (highlight key moments)
- [ ] Extract all vendor names to table above
- [ ] Extract all dish names to table above
- [ ] Extract all FAQ answers to table above

### Phase 2: Story Extraction (2-3 hours)

- [ ] Categorize stories by type (origin, vendor, guest, cultural)
- [ ] Add timestamps to each story
- [ ] Add direct quotes where powerful
- [ ] Map stories to pages they'll feed

### Phase 3: Content Mapping (1-2 hours)

- [ ] Map extracted content to specific pages
- [ ] Estimate word counts per page
- [ ] Prioritize pages (P0, P1, P2)
- [ ] Create content writing queue

### Phase 4: Follow-ups (1 hour)

- [ ] List all follow-up questions needed
- [ ] Send follow-up email to Pauline/Maarten
- [ ] Update extraction document with answers
- [ ] Mark extraction complete
