## 1. Sitemap.xml

### Current State

**File:** `/frontend/src/pages/robots.txt.ts` (auto-generated by Astro)

**Current Coverage:**
- ✅ Static pages (homepage, about, contact, etc.)
- ✅ Tour pages (7 main tours)

- ⚠️ Segment pages (not yet created)
- ⚠️ Location pages (2 locations only)

**Issues:**
- Sitemap is static — doesn't update when content is added to Directus
- Missing segment landing pages (13 pages we created)
- Missing location×segment pages (~50 pages)
- Missing blog posts (7 posts)

### Recommended Implementation

**Create Dynamic Sitemap Generator:**

**File:** `/frontend/src/pages/sitemap.xml.ts`

```typescript
import type { APIRoute } from 'astro';
import { getAllTours, getFeaturedStories, getSiteSettings } from '@/lib/directus';
import { getLangFromUrl } from '@/i18n/utils';

export const GET: APIRoute = async () => {
  // Fetch all content from Directus
  const tours = await getAllTours({ limit: 100 });
  const stories = await getFeaturedStories('en');
  const siteSettings = await getSiteSettings();
  
  // Segment pages (13 pages)
  const dietarySegments = ['vegetarian', 'halal', 'gluten-free', 'vegan', 'jain'];
  const specialtySegments = ['street-food', 'market-tour', 'heritage', 'night-tour'];
  const travelTypes = ['family', 'couples', 'solo', 'foodie'];
  
  // Build sitemap
  const urls = [
    // Static pages
    { url: 'https://simplyenak.com/', changefreq: 'daily', priority: 1.0 },
    { url: 'https://simplyenak.com/about/', changefreq: 'monthly', priority: 0.8 },
    { url: 'https://simplyenak.com/tours/', changefreq: 'weekly', priority: 0.9 },
    { url: 'https://simplyenak.com/contact/', changefreq: 'monthly', priority: 0.7 },
    { url: 'https://simplyenak.com/faq/', changefreq: 'monthly', priority: 0.7 },
    
    // Tour pages (from Directus)
    ...tours.map((tour: any) => ({
      url: `https://simplyenak.com/tours/${tour.slug}/`,
      changefreq: 'weekly',
      priority: 0.8,
    })),
    
    // Story pages
    ...stories.map((story: any) => ({
      url: `https://simplyenak.com/stories/${story.slug}/`,
      changefreq: 'monthly',
      priority: 0.6,
    })),
    
    // Segment pages
    ...dietarySegments.map(segment => ({
      url: `https://simplyenak.com/tours/dietary/${segment}/`,
      changefreq: 'monthly',
      priority: 0.7,
    })),
    
    ...specialtySegments.map(segment => ({
      url: `https://simplyenak.com/tours/specialty/${segment}/`,
      changefreq: 'monthly',
      priority: 0.7,
    })),
    
    ...travelTypes.map(type => ({
      url: `https://simplyenak.com/tours/travel-types/${type}/`,
      changefreq: 'monthly',
      priority: 0.7,
    })),
    
    // Location pages
    { url: 'https://simplyenak.com/tours/locations/kuala-lumpur/', changefreq: 'monthly', priority: 0.7 },
    { url: 'https://simplyenak.com/tours/locations/penang/', changefreq: 'monthly', priority: 0.7 },
  ];
  
  // Generate XML
  const sitemap = `<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  ${urls.map(url => `
    <url>
      <loc>${url.url}</loc>
      <changefreq>${url.changefreq}</changefreq>
      <priority>${url.priority}</priority>
    </url>
  `).join('')}
</urlset>`;

  return new Response(sitemap, {
    headers: {
      'Content-Type': 'application/xml',
    },
  });
};
```

**Benefits:**
- ✅ Dynamic — updates when content is added to Directus
- ✅ Includes all segment pages
- ✅ Proper priority settings
- ✅ Proper changefreq settings

**Implementation Time:** 1-2 hours
