## 📞 Recording Setup (Choose One)

### Option A: Zoom (Recommended)

**Setup:**
1. Create Zoom meeting
2. Enable cloud recording + auto-transcription
3. Send invite
4. Start 5 minutes early to test

**Pros:** Auto-transcription, video + audio, easy  
**Cons:** Requires internet

### Option B: Otter.ai (Best Transcription)

**Setup:**
1. Create Otter.ai account (free: 300 min/month)
2. Install app or use web
3. Start recording when interview starts

**Pros:** Live transcription, 85-90% accurate, speaker ID  
**Cons:** Requires subscription for longer interviews

### Option C: Phone Voice Recorder (Backup)

**Setup:**
1. Open Voice Memos (iPhone) or Voice Recorder (Android)
2. Create new recording
3. Place phone near speakers

**Pros:** Always available, reliable  
**Cons:** No auto-transcription, manual upload needed

## 🆘 Common Issues & Solutions

### Issue: "We don't have 90 minutes"

**Solution:** Split into two 45-minute sessions
- Session 1: Brand story + vendors (Q1-Q10)
- Session 2: Dietary + locations + culture (Q11-Q60)

### Issue: "We can't remember vendor names"

**Solution:** That's okay! Note it as follow-up:
- "We'll come back to the name — tell me more about the stall"
- Send follow-up email after interview: "What was the name of the laksa vendor?"

### Issue: "We're not sure about exact details"

**Solution:** Approximations are fine:
- "About 40 years" is good enough
- "Somewhere in Chinatown" can be verified later
- Content can be updated once confirmed

### Issue: "We don't have photos of vendors"

**Solution:** Not required for launch:
- Use placeholder images
- Take photos on next tour
- Add vendor photos post-launch
