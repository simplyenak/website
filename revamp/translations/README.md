# Translation Documentation

This folder contains documentation and guides for translation integration in the revamp project.

## Files

- `TRANSLATION_WORKFLOW.md` - Complete translation workflow
- `TRANSLATIONS_COMPLETE_FINAL.md` - Final translation completion status
- `TRANSLATIONS_INTEGRATION_GUIDE.md` - Integration guide for frontend
- `TRANSLATIONS_QUICK_REFERENCE.md` - Quick reference for translations
- `TRANSLATIONS_REVAMP_SETUP.md` - Setup guide for revamp project
- `TRANSLATIONS_SETUP_COMPLETE.md` - Setup completion documentation
- `TRANSLATIONS_SUMMARY.md` - Summary of translation work
- `COMPLETE_HOMEPAGE_TRANSLATIONS.md` - Homepage translations completion
- `HOMEPAGE_TRANSLATIONS_GUIDE.md` - Homepage translation guide

## Related Folders

- `/directus/translations/` - Directus translation scripts and schemas
- `/revamp/frontend/src/i18n/` - Frontend i18n implementation
