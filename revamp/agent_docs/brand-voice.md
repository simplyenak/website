# Brand Voice

## Three-feeling test — all three must pass before publishing

- **WELCOMED**: feels personally invited, like a friend not a customer
- **FASCINATED**: curious about hidden Malaysia, excited by stories
- **CONNECTED**: linked to Malaysian heritage, part of something meaningful

## Never use

authentic, authenticity, premium, luxury, world-class, discover, explore, immerse, journey, customer, client, participant, establishment, venue, facility, provide, offer, deliver, delicious, amazing, incredible (without specific detail), traditional / historic (without actual story or timeline), unique, special, exceptional (without the specific fact), best, #1, must-see, can't miss, "we are friends" (show it, never announce it), multiple exclamation points, ALL CAPS, em-dashes in outward-facing copy

## Always use

- Specific names: Aunty Lim, Uncle Chen, actual dish names
- Active invitation: "come with us", "we'll show you", "let us take you"
- Sensory details over generic labels
- Direct address: "you", "we'll", "you'll"
- Contractions naturally
- One `!` max per paragraph

## Word substitution

| Instead of... | Use... |
|--------------|--------|
| authentic | "where we eat", "where locals go" |
| premium | "places we love" |
| discover / explore | "see, taste, meet, try" |
| journey | "walk, visit, time" |
| traditional | "[specific generation / time period]" |
| unique | [the specific fact] |
| experience (noun) | "tour", "day with us" |
| must-see | "we always show our friends" |
| delicious | the specific flavour, texture, smell |
