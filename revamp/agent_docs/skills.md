# Available Skills

Invoke with the Skill tool.

| Skill | When to use |
|-------|------------|
| `simply-enak-requirements-clarifier` | Clarify and record decisions before building anything |
| `seo` / `seo-page` / `seo-technical` | Full SEO audit or single-page deep analysis |
| `seo-schema` | Add or validate JSON-LD structured data |
| `seo-blog-writer` | Write a story/blog post optimised to rank |
| `commit-commands:commit` | Stage and commit with a conventional message |
| `engineering-workflow-skills:git-pushing` | Commit + push in one step |
| `claude-md-management:revise-claude-md` | Update CLAUDE.md or agent_docs/ with session learnings |
| `webapp-testing` | Run Playwright tests against the local dev server |
| `superpowers:dispatching-parallel-agents` | Run multiple independent tasks in parallel |
