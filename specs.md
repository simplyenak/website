# Simply Enak Website Revamp - Project Specifications

## 📋 Project Overview

**Project Name**: Simply Enak Website Revamp - Local Development & Updates
**Project Type**: Website review, update, and local testing (no Strapi connections)
**Timeline**: Immediate start with phased approach
**Team Size**: 8 specialized agents + Project Manager
**Approach**: Specs-driven development with evidence-based validation

## 🎯 Project Objectives

### Primary Goals
1. **Review Current Website State** - Audit existing design, content, and functionality
2. **Update Business Content** - Ensure 4 tour packages reflect current pricing (RM 285-359)
3. **Implement "Passionate Friend" Brand Archetype** - Show, don't tell friendship through actions
4. **Optimize User Experience** - Mobile-first responsive design with smooth interactions
5. **Enhance Technical SEO** - Improve Core Web Vitals and search visibility
6. **Local Testing Capability** - Fully functional offline development environment

### Success Criteria
- Professional design reflecting 14-year established tour operator
- Content accuracy with current business offerings
- Mobile responsiveness across all breakpoints
- Evidence-based quality validation before production consideration
- Brand consistency across all touchpoints
- Technical performance excellence (Core Web Vitals > 90)

## 🏗️ Technical Specifications

### Frontend Stack
- **Framework**: Astro 5 (server-side rendering with hybrid static generation)
- **Languages**: TypeScript, JavaScript
- **Styling**: TailwindCSS 4
- **Components**: React (interactive), Vue (simple), Astro (static)
- **Build Tool**: npm with Astro CLI
- **Development Server**: Local dev server (port 4321)

### Backend Requirements
- **Status**: No Strapi connections for local development
- **Data Source**: Static/hardcoded content only
- **API**: Mock/placeholder data for testing forms
- **Database**: No external database connections

### Design System Requirements
- **Mobile-First**: Progressive enhancement from mobile to desktop
- **Accessibility**: WCAG 2.1 AA compliance minimum
- **Performance**: Core Web Vitals optimization (LCP < 2.5s, FID < 100ms, CLS < 0.1)
- **Brand Consistency**: "Passionate Friend" archetype enforcement

### Business Context
- **Company**: 14-year established premium Malaysian tour operator

- **Revenue Model**: Direct bookings preferred over OTAs
- **Team Structure**: 2 permanent + 1 VA + freelance guides
