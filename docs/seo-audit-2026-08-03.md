## Simply Enak — Key Findings

### ✅ Strengths
- **Schema markup**: LocalBusiness + FAQPage + Review + Person (founders) on homepage
- **i18n**: 10 languages properly served with hreflang
- **Content quality**: 93/100, low filler, good information density
- **Open Graph**: Complete (title, description, image, locale, site_name)
- **Internal linking**: 132 links on homepage (good crawlability)
- **Article schema**: Present (good for Discover eligibility)
- **GSC performance**: 45K+ impressions/month, top queries include "durian", "food tour penang"

### ⚠️ Issues Found

1. **Tour page 404**: `/tours/malaysian-food-tour-k Kuala-lumpur` returns 404
   - Need to verify correct slugs from sitemap
   - Check if tours are properly indexed

2. **Low CTR (1.31%)**: 45K impressions but only 590 clicks
   - Title/meta could be more compelling
   - Consider adding price, duration, rating to meta descriptions

3. **Duplicate FAQ entries**: Memory indicates FAQ schema has duplicate "Can children join this tour?" questions
   - Fix in Payload CMS (collapse to single entry with `page_visibility: all`)

4. **Missing tour-level schema**: Tour listing pages don't have schema
   - Add `ItemList` or `TouristAttraction` schema to tour pages

5. **No email capture**: Missing from site
   - Important for Google Discover (audience signal requirement)

## Culinary Travel Experts — Key Findings

### ✅ Strengths
- **Content quality**: 95/100, excellent
- **Basic schema**: Organization schema present
- **Open Graph**: Complete meta tags

### ⚠️ Issues Found

1. **Limited schema**: Only Organization schema on homepage
   - Add `ProfessionalService`, `TouristAttraction`, `Article` for deeper pages
   - Add B2B-specific schema (B2BService, Offer)

2. **Single language**: Only English sitemap

3. **No Article schema**: Missing for blog/stories content

4. **No GSC integration**: Missing Google Search Console tracking
   - Add verification tag and implement query monitoring
